# DineFlow — نظام تشغيل المطاعم

مشروع SaaS لإدارة المطاعم يُبنى على مراحل. يشمل نطاقه المنيو الرقمي، طلبات QR، الطاولات، المطبخ، نقطة البيع، الموظفين والصلاحيات، الفواتير والمدفوعات، التقارير، التسويق والذكاء الاصطناعي؛ راجع خريطة الطريق لمعرفة ما تم تسليمه وما لا يزال قيد التطوير.

> **الحالة:** قيد البناء خطوة بخطوة. كل خطوة تُسلَّم مكتملة وقابلة للتشغيل قبل الانتقال للتي بعدها.

## التشغيل السريع

### 1. المتطلبات

- Node.js 20+
- PostgreSQL 14+

### 2. التثبيت

```bash
git clone https://github.com/charleprawn-debug/menu.git
cd menu
npm install
```

### 3. متغيرات البيئة

```bash
cp .env.example .env
```

عدّل `DATABASE_URL` ليشير إلى قاعدة بياناتك. قبل النشر العام، اضبط `NEXT_PUBLIC_APP_URL` على النطاق العام الحقيقي؛ بدونه لا يصدر التطبيق canonical أو sitemap مطلقاً. ثم:

```bash
npx prisma migrate dev
npm run db:seed
```

### 4. التشغيل

```bash
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## الحسابات التجريبية

كلمة المرور للجميع: `Admin123!`

| الدور | البريد |
| --- | --- |
| مدير المنصة (Super Admin) | `admin@dineflow.app` |
| مالك المطعم | `owner@dineflow.app` |
| المدير العام | `manager@dineflow.app` |
| نادل | `waiter@dineflow.app` |
| كاشير | `cashier@dineflow.app` |
| شيف | `chef@dineflow.app` |
| محاسب | `accountant@dineflow.app` |

المطعم التجريبي: **مطعم البيت الشامي** — المنيو العام على `/ar/r/demo` أو `/en/r/demo`. صفحات التسويق تستخدم بادئة اللغة، مثل `/ar/features` و`/en/pricing`. رسائل التواصل تظهر في `/ar/admin/inquiries` للمشرف الأعلى. المنيو العام حالياً للتصفح؛ سلة الضيف والطلب عبر QR قادمان في الخطوة 11. أزرار الأسعار تفتح إنشاء الحساب فقط ولا تختار باقة مدفوعة أو تبدأ تحصيلاً؛ تهيئة المطعم قد تنشئ سجلاً أولياً للتجربة وفق الخطة، بينما إدارة التجربة والاشتراك والفوترة ستُستكمل في الخطوة 3.

## بنية المشروع

```
prisma/
  schema.prisma        # 70+ موديل: هوية، صلاحيات، منيو، طلبات، طاولات، فواتير، اشتراكات…
  seed.ts              # بذور المنصة (باقات، ميزات، أدوار، مستخدمون)
  seed-demo.ts         # بذور المطعم التجريبي (منيو، طلبات، حجوزات، تقييمات…)
src/
  app/
    (auth)/            # تسجيل الدخول، إنشاء حساب، استعادة كلمة المرور
    (marketing)/       # صفحات الموقع التسويقي والميزات والأسعار والقانونيات
    app/               # لوحة تحكم المطعم
    admin/             # لوحة إدارة المنصة وصندوق استفسارات الموقع
    r/[slug]/          # المنيو العام للزبائن
    onboarding/        # تهيئة المطعم
    actions/           # Server Actions
  components/
    ui/                # نظام التصميم (Button, Dialog, Table, Select…)
    layout/            # الهيكل العام (Sidebar, Topbar, Command menu)
    brand/             # الشعار ومبدّل اللغة
    marketing/         # Header/Footer التسويقي
    charts/            # رسوم Recharts
  i18n/                # قاموس عربي/إنجليزي + مزوّد العميل
  lib/
    auth/              # الجلسات، كلمات المرور، الحراسة
    services/          # خدمات النطاق (تهيئة المطعم…)
    validations/       # مخططات Zod
    db.ts, money.ts, permissions.ts, navigation.ts, status.ts
```

## خريطة الطريق

يُبنى المشروع على 12 خطوة، وكل خطوة تُسلَّم كاملة:

- [x] **الخطوة 1 — الأساس:** المستودع، قاعدة البيانات (70+ موديل)، المصادقة والجلسات، RBAC، i18n/RTL، نظام التصميم، هيكل لوحة التحكم، الموقع التعريفي، المنيو العام، البذور الكاملة.
- [x] **الخطوة 2 — الموقع التسويقي:** الرئيسية، فهرس و11 صفحة ميزات، أسعار ديناميكية ومقارنة شهرية/سنوية، من نحن، تواصل مع صندوق وارد آمن، FAQ، الشروط والخصوصية، URLs عربية/إنجليزية قابلة للمشاركة وSEO/sitemap/robots.
- [ ] **الخطوة 3 — الاشتراك والتهيئة:** معالج Onboarding من 6 خطوات، إدارة الاشتراك والفواتير والترقية.
- [ ] **الخطوة 4 — المنيو:** أقسام، منتجات، إضافات، مجموعات خيارات، عروض، مواسم، ترتيب وسحب، تصميم المنيو.
- [ ] **الخطوة 5 — الطاولات وQR:** مخطط الصالة، الجلسات، الحجوزات، استدعاء النادل، مولّد أكواد QR وتصديرها.
- [ ] **الخطوة 6 — الطلبات:** دورة حياة الطلب الكاملة، الطلب اليدوي، الفلاتر، السجل الزمني، الإشعارات الحية.
- [ ] **الخطوة 7 — المطبخ ونقطة البيع:** شاشة المطبخ بالمحطات والمؤقتات، POS، شاشة النادل.
- [ ] **الخطوة 8 — الموظفون والصلاحيات:** دعوات، أدوار مخصصة، مصفوفة صلاحيات، سجل النشاط.
- [ ] **الخطوة 9 — الفواتير والتقارير:** فواتير، مدفوعات، مرتجعات، مصروفات، 6 تقارير مع تصدير CSV.
- [ ] **الخطوة 10 — التسويق والذكاء الاصطناعي:** كوبونات، حملات، ولاء، تقييمات، مساعد AI.
- [ ] **الخطوة 11 — منيو الزبون والطلب:** منيو عام كامل، سلة، تتبع الطلب، تقييم، حجز.
- [ ] **الخطوة 12 — لوحة المنصة والنشر:** Super Admin كامل، فحص نهائي، توثيق، نشر.

## ملاحظات التصميم

- **عربي أولاً:** كل واجهة تعمل RTL بالكامل، والقاموس يغطي العربية والإنجليزية.
- **ألوان العلامة:** أخضر زمردي `#059669` أساسي، مع لوحة محايدة دافئة.
- **الوصول:** تباين مدروس، حالات تركيز واضحة، وأهداف لمس مناسبة للجوال.
- **الأداء:** Server Components افتراضياً، وClient Components فقط عند الحاجة للتفاعل.
